# fanhuawork.github.io

[English](README.md) | 简体中文

介绍游戏服务与相关资源的归档静态网站。

归档项目，保留用于参考。

## 项目概述

网站包含首页、各游戏的服务说明与静态资源。项目首页仅保留服务目录，移除个人资料和招募信息。

## 技术栈与依赖

HTML、CSS 与图片资源。需要浏览器和静态 HTTP 服务器，可选用 Python 3；仓库无前端包管理或构建流程。

## 文件结构

- `index.html` — 首页
- `job/` — 游戏服务页面
- `static/` — 样式与图片
- `404.html` — 错误页面

## 快速上手

在仓库根目录启动静态服务器，以正确加载绝对路径资源：

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000/`。直接编辑 HTML 和静态资源，无需前端构建。
